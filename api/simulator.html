Simulator¶

This module defines the Simulator class, which provides numerical tools to simulate the interplay between population games, payoff mechanisms, and revision processes.

The simulator tracks the evolution of strategic distributions and payoffs over time. It supports both finite-agent simulations and numerical integration of deterministic dynamics models.

The simulator is equipped with a VisualizationMixin implementing useful visualization tools.

Simulates the interplay between the three core objects: i) A population game, ii) A payoff mechanism, and iii) a list of revision processes (one per population).

Initialize the simulator object.

Parameters:

  • population_game (PopulationGame) – The population game object.

  • payoff_mechanism (PayoffMechanism) – The payoff mechanism object.

  • revision_processes (Union[RevisionProcessABC, list[RevisionProcessABC]]) – A single revision process for the single-population case, or a list of revision processes for the multi-population case, where each element corresponds to a specific population.

  • num_agents (Union[int, list[int]]) – The number of agents as an integer for the single-population case, or a list of integers specifying the number of agents in each population for the multi-population case.

  • fast_path (bool) – Whether to use the fast simulation path. It is only used if all revision processes are PoissonRevisionProcess instances; otherwise the per-agent simulation path is used. Set to False to force the per-agent path (e.g., for comparison). Defaults to True.

  • pdm_method (str) – Method used to integrate the PDM between revision events. Either ‘RK4’ or any method supported by scipy.integrate.solve_ivp (e.g., ‘Radau’ for stiff PDMs). Defaults to ‘RK4’.

  • pdm_max_step (float) – Maximum step size used to integrate the PDM between revision events. Defaults to 0.01.

  • seed (Union[int, np.random.Generator], optional) – Seed or random number generator for the simulation. Defaults to None, in which case NumPy’s global random state is used (see np.random.seed). Custom (non-Poisson) revision processes always draw from their own random sources.

  • backend (str) – Either ‘numpy’ or ‘numba’. The ‘numba’ backend compiles the fast simulation path with Numba (requires pip install popgames[numba]). It requires the fast path, built-in revision protocols, pdm_method='RK4', and payoff mechanism functions that can be compiled with numba.njit; otherwise, a warning is logged and the ‘numpy’ backend is used. Compilation takes a few seconds on the first run of each session. Defaults to ‘numpy’.

integrate_ensemble(T_sim, x0=None, q0=None, t_eval=None, method='Radau')[source]¶

Integrate the deterministic approximation (EDM-PDM) from several initial states, e.g., to check that every trajectory converges regardless of where it starts.

Each run r is integrate_edm_pdm from (x0_r, q0_r) over [0, T_sim], sampled at the times t_eval. The result is an EnsembleResult (with is_deterministic=True and no seeds), so it supports the same statistics and plots as the ensembles of finite-agent simulations from run_ensemble. For instance, ens.plot(plot_type='bands', statistic='mean_std') shows the mean and standard deviation over the initial states.

The initial states can be shared by all runs or given per run, as in run_ensemble:

  • x0: an array of shape (n, 1) (or None) shared by all runs, or an array of shape (M, n, 1) with one initial state per run (see popgames.utilities.sample_initial_states). Similarly for q0.

The number of runs M is the length of the per-run arguments (which must agree), or 1 if there are none.

Parameters:

  • T_sim (float) – The time horizon of each run.

  • x0 (np.ndarray, optional) – The initial strategic distribution, of shape (n, 1) for all runs or (M, n, 1) per run. Defaults to None, in which case the initial state of the last reset (log.x[:, [0]]) is used.

  • q0 (np.ndarray, optional) – The initial state of the PDM, of shape (d, 1) for all runs or (M, d, 1) per run. Defaults to None, in which case the initial state of the last reset (log.q[:, [0]]) is used.

  • t_eval (np.ndarray, optional) – Non-decreasing times in [0, T_sim] at which the runs are sampled. Defaults to None, in which case 201 evenly spaced times are used.

  • method (str, optional) – The integration method (see integrate_edm_pdm). Defaults to ‘Radau’.

Returns:

The sampled runs, with fields t (shape (K,)), x (shape (M, n, K)), q (shape (M, d, K)), p (shape (M, n, K)), x0 (shape (M, n, 1)), and q0 (shape (M, d, 1)), where K is the number of sampling times.

Return type:

EnsembleResult

property log: SimpleNamespace¶

The simulation log since the last reset, with one row per variable and one column per log entry.

The layout is the same as the output of run and integrate_edm_pdm (and of scipy.integrate.solve_ivp), so finite-agent and deterministic trajectories can be compared directly. Standard NumPy indexing applies:

  • log.x[i] (shape (K,)) is the trajectory of strategy i over time.

  • log.x[:, k] (shape (n,)) is the strategic distribution at time log.t[k].

  • log.x[:, [k]] (shape (n, 1)) is the same distribution as a column vector, as expected by reset, integrate_edm_pdm, and the payoff functions.

Returns:

The log with fields t (shape (K,)), x (shape (n, K)), q (shape (d, K)), and p (shape (n, K)), where K is the number of log entries.

Return type:

run_ensemble(T_sim, num_runs=None, t_eval=None, seed=None, x0=None, q0=None, log_interval=None)[source]¶

Run several finite-agent simulations, e.g., from the same initial state with different seeds, or from different initial states.

Each run r resets the simulator with reset(x0_r, q0_r, seed=seed_r) and runs it for T_sim time units. Its state is then sampled at the times t_eval: the value at time t is the state after the last revision event at or before t (the state of a finite population is constant between events).

The seeds and the initial states can be shared by all runs or given per run:

  • seed: an integer, a np.random.Generator, or None to derive independent seeds for the runs, or a sequence with one seed per run (e.g., [7] * M to use the same seed in all runs).

  • x0: an array of shape (n, 1) (or None) shared by all runs, or an array of shape (M, n, 1) with one initial state per run (see popgames.utilities.sample_initial_states). Similarly for q0.

The number of runs M is num_runs or the length of the per-run arguments (which must agree).

After the call, the simulator holds the last run (e.g., in log), and its random number generator is the one it had before the call.

Parameters:

  • T_sim (int) – The total time to simulate in each run.

  • num_runs (int, optional) – The number of runs. Defaults to None, in which case it is the length of the per-run arguments (required if there are none).

  • t_eval (np.ndarray, optional) – Non-decreasing times in [0, T_sim] at which the runs are sampled. Defaults to None, in which case 201 evenly spaced times are used.

  • seed (Union[int, np.random.Generator, Sequence[int]], optional) – Seed or random number generator from which independent seeds for the runs are derived, or a sequence of non-negative integers with the seed of each run. Defaults to None, in which case the seeds are derived from the simulator’s random number generator (NumPy’s global random state if the simulator has no seed, see np.random.seed).

  • x0 (np.ndarray, optional) – The initial strategic distribution, of shape (n, 1) for all runs or (M, n, 1) per run. Defaults to None, in which case the initial state of the last reset (log.x[:, [0]]) is used for all runs.

  • q0 (np.ndarray, optional) – The initial state of the PDM, of shape (d, 1) for all runs or (M, d, 1) per run. Defaults to None, in which case the initial state of the last reset (log.q[:, [0]]) is used for all runs.

  • log_interval (float, optional) – Minimum time between consecutive log entries within each run (see run). Defaults to None, in which case every revision event is logged and the sampled states are exact. Setting it reduces memory usage in very large runs, but then the state sampled at time t may lag behind by up to log_interval.

Returns:

The sampled runs, with fields t (shape (K,)), x (shape (M, n, K)), q (shape (M, d, K)), p (shape (M, n, K)), seeds (shape (M,)), x0 (shape (M, n, 1)), and q0 (shape (M, d, 1)), where K is the number of sampling times.

Return type:

EnsembleResult

class popgames.ensemble.EnsembleResult(simulator, t, x, q, p, seeds, x0, q0, is_deterministic=False)[source]¶

Bases: EnsembleVisualizationMixin

Simulations sampled at common times, e.g., from the same initial state with different seeds, or from different initial states.

Ensembles of finite-agent simulations are created by Simulator.run_ensemble, and ensembles of the deterministic approximation (EDM-PDM) from several initial states by Simulator.integrate_ensemble. The arrays have one leading axis for the runs, followed by the layout of Simulator.log:

  • ens.x[r] (shape (n, K)) is run r, with ens.x[r, i] the trajectory of strategy i.

  • ens.x[:, i] (shape (M, K)) holds the trajectories of strategy i in all runs.

  • ens.x[:, :, k] (shape (M, n)) holds the strategic distributions of all runs at time ens.t[k].

Runs with the same initial state (x0, q0) form a group (groups and group_index). Statistics such as mean and quantile pool all runs; use subset for statistics per group, e.g., ens.subset(ens.groups[g]).mean(). The plots show one group per initial state, unless the initial states are pooled (the default for deterministic ensembles, see plot_ensemble_bands).

plot(*, plot_type='bands', **kwargs)¶

Unified plotting interface for ensembles of finite-agent simulations.

Supported plot types (see their functions in popgames.plotting.ensemble_plotters for all options):

  • 'bands': median and quantile bands (or mean and standard deviation bands, statistic='mean_std') of x, p, and q over time, per initial state or pooled, in one panel or one panel per strategy, with optional reference lines such as an equilibrium, and of quantities derived from the state (plot_ensemble_bands).

  • 'kpi': the same bands for a KPI over time (plot_ensemble_kpi).

  • 'ternary': trajectories of the runs on the simplex (plot_ensemble_ternary).

  • 'final': distribution of the strategic distributions at the final (or a given) time (plot_ensemble_final).

All plot types accept filename, figsize, fontsize, show, plot_deterministic_approximation, and ax (existing matplotlib axes to draw on, one per figure the plot would otherwise create; the figure is then neither saved, shown, nor closed).

Parameters:

  • **kwargs (Any) – Keyword arguments of the selected plot type. Unrecognized arguments raise a TypeError.

Unified plotting interface for ensembles of finite-agent simulations.

popgames.plotting.ensemble_plotters.plot_ensemble_bands(ensemble, variables=('x', 'p', 'q'), bands=((0.05, 0.95), (0.25, 0.75)), plot_median=True, plot_deterministic_approximation=False, initial_state=None, pool_initial_states=None, statistic='quantile', num_std=(1,), linewidth=1.0, band_alpha=None, layout='joint', ncols=3, reference=None, plot_gne=False, reference_style=None, derived=None, xlim=None, ylim=None, filename=None, figsize=None, fontsize=8, show=True, ax=None, legend=True)[source]¶

Plot the median and quantile bands (or the mean and standard deviation bands) of the runs over time.

One figure is generated per population for x and p, and one for q (if d > 0). Each strategy has its own color: the solid line is the median over the runs, and the shaded regions are the bands between the given quantiles (e.g., 90% and 50% of the runs at each time with the default bands). With statistic='mean_std', the solid line is the mean instead, and the bands are the mean plus or minus num_std standard deviations.

With layout='joint', all the strategies of a figure share one panel. With layout='per_strategy', each strategy has its own panel (titled with the strategy), laid out in a grid of ncols columns sharing the time axis, e.g., for games with many strategies. Reference values, such as an equilibrium, are plotted as dashed horizontal lines in the color of each strategy, and the deterministic approximation as dotted lines.

Quantities derived from the state (derived), e.g., temperatures that depend on x, are plotted like the variables, after them. Their statistics are computed on the derived values of the runs (which differs from applying the function to the statistics of x if the function is nonlinear).

By default, the bands of a finite-agent ensemble only mix runs with the same initial state: if the ensemble has several initial states (groups), the figures are generated for each of them (or only for initial_state). With pool_initial_states=True, the bands mix all runs instead, e.g., to show how trajectories from many initial states converge. This is the default for deterministic ensembles (Simulator.integrate_ensemble), which have a single run per initial state.

Parameters:

  • ensemble (EnsembleResult) – The ensemble to plot.

  • variables (Sequence[str], optional) – The variables to plot, among ‘x’, ‘p’, and ‘q’. Defaults to all of them. Use [] to plot only the derived quantities.

  • bands (Sequence[tuple[float, float]], optional) – Pairs of lower and upper quantiles delimiting the bands (with statistic='quantile'). Defaults to ((0.05, 0.95), (0.25, 0.75)).

  • plot_median (bool, optional) – Whether to plot the central line: the median, or the mean with statistic='mean_std'. Defaults to True.

  • plot_deterministic_approximation (bool, optional) – Whether to plot the trajectories of the deterministic approximation (EDM-PDM) as dotted lines (when pooling several initial states, the same statistic as the central line over their trajectories). Ignored for deterministic ensembles. Defaults to False.

  • initial_state (int, optional) – The group (initial state) to plot, see EnsembleResult.groups. Defaults to None, in which case all groups are plotted. Cannot be combined with pool_initial_states=True.

  • pool_initial_states (bool, optional) – Whether the bands mix the runs of all initial states, in a single set of figures. Defaults to None, in which case it is True for deterministic ensembles and False otherwise.

  • statistic (str, optional) – ‘quantile’ for the median and quantile bands, or ‘mean_std’ for the mean and bands of plus or minus num_std (population) standard deviations. Note that the latter may leave the feasible region, e.g., become negative. Defaults to ‘quantile’.

  • num_std (Sequence[float], optional) – The widths of the bands in standard deviations (with statistic='mean_std'). Defaults to (1,).

  • linewidth (float, optional) – Line width of the central line. Defaults to 1.

  • band_alpha (float | Sequence[float], optional) – Opacity of the bands: one value for all of them, or one per band (widest first). Defaults to None, in which case 0.15 for the widest band, 0.25 for the next one, etc.

  • layout (str, optional) – ‘joint’ for one panel per figure, or ‘per_strategy’ for one panel per strategy. Defaults to ‘joint’.

  • ncols (int, optional) – Number of columns of the grid of panels (with layout='per_strategy'). Defaults to 3.

  • reference (dict[str, np.ndarray], optional) – Reference values plotted as dashed horizontal lines, per variable or derived quantity, e.g., {'x': x_star} with x_star of shape (n, 1). A scalar is used for all entries, e.g., {'T': 30.0}. Defaults to None.

  • plot_gne (bool, optional) – Whether to plot the GNE (if one is found) as the reference of x. Cannot be combined with reference['x']. Defaults to False.

  • reference_style (dict, optional) – Keyword arguments of matplotlib.axes.Axes.axhline overriding the style of the reference lines (dashed, in the color of each entry), e.g., {'color': 'black', 'linestyle': 'dotted'}. Defaults to None.

  • derived (dict[str, Callable[[SimpleNamespace], np.ndarray]], optional) – Quantities derived from the state, by name (a short symbol, used in the labels, e.g., 'T'): functions mapping a run (see EnsembleResult.apply) to an array of shape (m, K), one row per entry. Defaults to None.

  • xlim (tuple[float, float], optional) – Limits of the time axis. Defaults to None.

  • ylim (dict[str, tuple[float, float]], optional) – Limits of the vertical axis per variable or derived quantity, e.g., {'x': (0, 1)}. Defaults to None.

  • filename (str, optional) – If provided, each figure is saved with the variable and population (and the group, if there are several and they are not pooled) appended to the file name, e.g., bands_x_1.pdf or bands_x_1_x0_2.pdf. Defaults to None.

  • figsize (tuple[float, float], optional) – Figure size. Defaults to None, in which case (4, 2) is used per panel.

  • fontsize (int, optional) – Font size. Defaults to 8.

  • show (bool, optional) – Whether to show the figures. Defaults to True.

  • ax (Axes | Sequence[Axes], optional) – Existing matplotlib axes to draw on, one per panel that would otherwise be generated, in the order of the initial states (unless pooled) and, for each one, of x (per population), p (per population), q, and the derived quantities (and of the entries, with layout='per_strategy'), e.g., the array of axes from plt.subplots(2, 3).
